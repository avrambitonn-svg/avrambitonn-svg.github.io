# Genair Ops — האפליקציה

React 19 + TypeScript + Vite. הנתונים, ההתחברות והסנכרון בזמן אמת עוברים דרך Supabase (ראו [`../supabase/CONTRACT.md`](../supabase/CONTRACT.md)).

## מצבי בנייה

המצב נקבע בבנייה, לפי `VITE_SUPABASE_URL` ו-`VITE_SUPABASE_KEY`:

| פקודה | מה יוצא | מצב |
|---|---|---|
| `npm run build` | `dist/` (אתר סטטי) | **ייצור**: מחובר ל-Supabase, כניסה עם טלפון נייד (או אימייל) וסיסמה, נתונים משותפים לכל הצוות |
| `npm run build:single` | `dist-single/index.html` (קובץ אחד) | **ייצור**, כמו למעלה. זה הקובץ של ההתקנה ב-Windows (`desktop/windows`) |
| `npm run build:demo` | `dist/` | **הדגמה**: בלי Supabase, הנתונים נשמרים בדפדפן בלבד, עם החלפת תפקידים וסיור מודרך |
| `npm run build:single:demo` | `dist-single/index.html` | הדגמה בקובץ אחד |
| `VITE_BRAND=demo npm run build:demo` | `dist/` | הדגמה עם מותג ניטרלי (בלי שם, טלפון וכתובת של ג'נאייר) |
| `npm run dev` | שרת פיתוח | הדגמה (אין `.env.development`) |

- הכתובת והמפתח של הפרויקט נמצאים ב-`.env.production`. המפתח הוא publishable: מיועד לדפדפן, וההרשאות נאכפות במסד.
- `.env.demo` מרוקן אותם, ולכן `--mode demo` בונה את ההדגמה.
- לבדיקה מול פרויקט אחר: `VITE_SUPABASE_URL=... VITE_SUPABASE_KEY=... npm run build` (משתני סביבה גוברים על הקבצים).
- מדיניות האבטחה (CSP) בבנייה הרגילה מתירה את כתובת הפרויקט (`https://` ו-`wss://` ל-Realtime) לפי `VITE_SUPABASE_URL`.

## במצב ייצור

- **כניסה**: טלפון נייד וסיסמה; מי שאין לו טלפון במערכת נכנס עם האימייל. החשבון ב-Supabase Auth הוא `<טלפון>@phone.genair.app` או האימייל.
- **הקמה ראשונה**: כשהמסד ריק, במקום מסך הכניסה מופיעה ההקמה: מעלים את הנתונים (מהדפדפן הזה, מקובץ גיבוי, או מערכת חדשה עם מנהל אחד), בוחרים מנהל וסיסמה, ומזינים את קוד ההקמה (`BOOTSTRAP_TOKEN` בסודות של פונקציית ה-Edge).
- **סיסמאות לעובדים**: עמוד המשתמשים ← מפתח ליד העובד (מנהל בלבד). סיסמה זמנית מוצגת פעם אחת, והעובד מחליף אותה בכניסה הראשונה.
- **סנכרון**: כל שינוי נשלח למסד (`db_ops`), ועדכונים מגיעים בזמן אמת (Realtime) ובבדיקה כל 30 שניות. בלי קליטה העבודה נשמרת במכשיר ונשלחת כשהחיבור חוזר.
- **אינטגרציות וקבצים** (Priority, AI, וואטסאפ, Google, העלאת קבצים, האזור האישי וטופס הפנייה): פונקציית ה-Edge `api` בכתובת `https://<project>.supabase.co/functions/v1/api/...`.
